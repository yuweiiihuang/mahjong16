# 多人連線

在首頁或牌桌右上點「多人連線」，輸入名稱後點「建立房間」，再複製邀請網址。朋友可開啟網址確認加入，
也可從同一選單輸入八碼房號。房主按「開始對局」。每桌最多四位真人，空位由電腦補上。
已入座的玩家可直接重整原房間網址，或從首頁點「返回房間」。

開局後也可接替未被真人保留的電腦座位，接著打該座位目前的手牌、分數及回合。
點「多人連線」中的「離開房間」並確認，即會讓出座位。可點自己的頭像修改牌桌顯示名稱，
名稱會同步給同桌玩家，帳號與固定玩家 ID 不受影響。

## 同步、重連與續局

- 伺服器處理合法操作、版本及座位驗證。用 HTTP 長輪詢接收狀態、用 POST 操作，
  重送同一操作不會執行第二次，版本過期須依最新牌況重新選擇。
- 每人只看得到自己的暗手、合法操作與公開牌。伺服器依碰、槓、胡等規則優先序統一裁決，
  同順位依座位距離，不公開其他玩家尚未成立的選擇。
- 短暫斷線仍保留座位。超過 90 秒由電腦接手，原玩家仍可回來接續。
  房主主動離開或斷線超過 90 秒時，若有其他在線玩家，房主會交接。
- 匿名玩家用原瀏覽器的 Cookie 回桌。啟用可信閘道時，同一帳號可跨裝置找回同一座位，
  不同帳號各有自己的固定玩家 ID。
- 房間由單一伺服器程序管理。空房或超過一小時未活動的房間會清理。這類房間的已保存紀錄
  仍可查閱，但無法續局。若因伺服器重啟中斷，符合[續局條件](hand-recording.md#網頁續局與重播)
  的對局可從「牌局紀錄／續局」恢復。

## 吃碰槓與聽牌

預設場規下，上家的棄牌可碰或胡，不能槓。碰牌後要等下一次正常摸牌，才能對該碰牌加槓。
吃牌後，本次不能打出與吃進牌相同的牌種，也不能用那張牌宣告聽牌。場規可分別調整
`allow_upstream_gang`、`allow_immediate_kakan_after_pong` 與 `allow_same_tile_discard_after_chi`。

聽牌提示會顯示可打出的牌與未見張數。點「聽」選牌並宣告，只有一種候選時直接宣告。
一般出牌只會改變聽牌狀態。「牌桌設定」可切換多種吃牌的選法，也可關閉宣告後自動出牌。

## 每席電腦強度

房主可在牌桌設定調整各席的標準／進階強度，修改於下一手生效。偏好跟隨座位，
真人斷線時供託管使用。進階搜尋未配置、逾時或失敗時，該席本手改用標準，
畫面會標註原因，下一手再嘗試進階。建置、容量及程序重用見 [MeowCaTS](meowcats.md#網頁牌桌)。

## 部署與驗收

[Docker 自架指南](docker.md#分享牌桌) 說明如何用有驗證的 HTTPS 入口分享牌桌。
邀請遠端朋友時，請從對方可開啟的 HTTPS 網址建立房間。反向代理應保留原始 `Host`、覆寫
`X-Forwarded-Proto: https`、給長輪詢至少 30 秒等待時間，並停用 `/api/` 快取。
同一服務請維持單一程序，避免請求分到不同的記憶體房間。

本機可用不同瀏覽器或無痕視窗模擬不同玩家。測試涵蓋手牌隔離、重連、重送和多人操作，
步驟見 [Web 測試指南](../tests/web/README.md)。
