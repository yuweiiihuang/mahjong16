# 青禾朋友連線（第一版）

入口仍是 `python -m app.web --port 8000`，牌桌仍使用 `ui/web/`。
點「朋友連線」建立房間，分享邀請網址；朋友開局前加入，房主按「開始對局」。
最多四位真人，空位由電腦補上。開局後仍可加入，依座位順序接替未被真人保留的電腦空位。
接替時保留手牌、摸牌、副露、花牌、棄牌、分數、宣告聽牌及當前回合；不重新發牌。
若該電腦正在思考，取消尚未執行的思考等待，改由加入的玩家操作；已送出的反應仍保留。

手機與桌面皆可從右上角「朋友連線 → 離開房間」正式退出，確認後釋放座位，便可加入其他房間。

## 吃碰槓限制

- 不可槓上家的棄牌，仍可選碰或胡；其他家的棄牌仍可槓。
- 碰牌後本次出牌不能加槓，等下一次正常輪到自己摸牌後解除，暗槓補摸不會提前解除。
- 吃牌後，本次不能打出與吃進牌相同的牌種，也不能用該牌宣告聽牌。成功打出其他牌後解除。
  手牌中的相同牌種會略微變暗並停用點擊；不限制順子的其他牌種。
- 以上為引擎預設規則，可透過 `Ruleset` 的 `allow_upstream_gang`、
  `allow_immediate_kakan_after_pong`、`allow_same_tile_discard_after_chi` 個別放寬。

## 同步與重連

- 伺服器持有唯一牌局，逐一驗證座位、版本和合法操作。
- 每個玩家只收到自己的手牌、合法操作及公開牌；他人的暗槓與聽牌資訊會遮蔽。
- 可聽牌時，右下角以棄牌 → 聽牌與未見張數顯示提示，相同組合合併，依選項數自然展開。
  輪到自己時顯示「聽／過」。按「聽」會抬起所有可宣告的候選牌，再點其中一張即出牌並宣告聽牌。
  若只有一種可宣告的棄牌，按「聽」即直接出牌並宣告，相同牌種不重複計算選項。
  也可先選中要打出的牌，再按「聽」；該牌可宣告時直接完成，否則仍進入候選牌選擇模式。
  按「過」會放下候選牌並隱藏本次出牌的聽牌按鈕，提示仍保留；再按「聽」只取消選擇模式。
  手牌差一張可胡是「聽牌狀態」，與「宣告聽牌」分開：一般出牌不會宣告，仍能自由改打手牌。
  若出牌後仍可聽，提示在其他玩家操作期間持續顯示；牌組不再可聽時隱藏。
  宣告後才在玩家狀態顯示「已宣告聽牌」，摸牌不能胡時會自動打出；可以胡時保留胡牌或打摸牌的選擇，提示持續顯示。
  「牌桌設定 → 聽牌後自動出牌」預設開啟，可自行關閉；每位玩家各自設定，重新開啟網頁會保留。
  關閉後仍遵守宣告聽牌的出牌限制，但摸牌改為手動出牌。
- 用原生 HTTP 長輪詢等待版本更新（最多 20 秒），操作使用 POST；不新增連線套件。
- 操作編號避免重送造成重複執行；過期版本必須重新選牌。
- 棄牌後所有尚未回應的玩家同時取得自己的吃／碰／槓／胡／過選項，
  每人只能選一次。伺服器依既有優先權統一裁決，不依點擊先後；
  已有選擇時，只等待仍有合法操作能改變結果的玩家。
  例如碰已確定且其他人最多只能吃，就立即裁決；若仍可能胡牌或有更高順位，繼續等待。
  同順位依座位距離決定，只有更近且仍可選同順位操作的人需要等待；全員過牌仍只摸一次。
- 尚未成立的選擇只回傳給本人，不更新共用版本，不公開回應者或回應進度。
  畫面只顯示已選按鈕，維持原本外觀與位置並停用，其他選項隱藏；只播放最後成立的動作。
- 無其他合法動作時自動過；電腦與斷線接手的玩家不會等待另一位真人先回應。
  多種吃牌選擇不開遮罩視窗；在「牌桌設定 → 多種吃牌選擇」可切換：
  「選順子組合」直接點選三張牌的組合；「選兩張手牌後確認」在手牌中選兩張，再按「確認」。
  預設選順子組合，偏好保留到下次開啟；兩種方式都可取消，只有送出後才算回應。
  目前不新增回應倒數或假停頓，等待時間仍可能提供資訊線索。
- 機器人的思考與出牌間隔由伺服器統一安排；連線桌固定自然節奏。
- 身分存在 HttpOnly cookie；重新整理與短暫斷線保留座位。
  超過 90 秒由電腦接手，回到同一瀏覽器可繼續；主動離開會讓出座位供電腦或新玩家接替；再次加入時不保證回到原座位。
  斷線玩家仍保留身分與座位，新玩家不能佔用該座位。
- 房主離開時交給仍在桌上的玩家；斷線超過 90 秒則交給在線玩家，
  保留原房主座位供重連。只有目前房主能開始或進入下一局。

房間與對局目前存在單一程序記憶體內。伺服器重新啟動會清除房間，
不支援跨裝置找回身分、觀戰、公開配對或多個伺服器副本。
無真人的房間立即清理；整桌一小時沒有請求也會清理。
上限 100 個房間、1,000 個瀏覽器身分；滿額時回傳錯誤。

## 本機驗收

不同瀏覽器或無痕視窗代表不同玩家；同一瀏覽器的一般分頁共用座位。
也可以分別開 `http://localhost:8000` 與 `http://127.0.0.1:8000` 驗證兩個身分。
同主機上不同連接埠使用不同 cookie 名稱，測試桌不影響既有練習桌。

```bash
source .venv/bin/activate
pytest -q
node --test tests/web/test_hand_sort.mjs tests/web/test_table_layout.mjs
```

`tests/web/test_multiplayer.py` 覆蓋獨立身分的 HTTP 加入與長輪詢、
手牌隔離、同時操作、重送、過期操作、機器人節奏與斷線接手，
以及四位玩家完整對局與原引擎結果一致。

## 網際網路部署

需要一台持續運行 Python 程序的主機，前方使用 HTTPS 反向代理。
只把代理的 HTTPS 入口公開；Python 預設綁定 `127.0.0.1`。
代理必須保留原始 `Host`、覆寫 `X-Forwarded-Proto: https`，
並允許至少 30 秒的請求等待；勿快取 `/api/`，並限制連線與請求速率。
目前內建 HTTP 伺服器供驗收與小型試用，尚未經公開服務的負載驗證。
第一版只能運行一個服務程序，不可使用會分流至不同程序的多 worker 設定。

部署後在公開 HTTPS 網域建立房間再分享網址。
本機 `localhost` 邀請網址無法供遠端朋友使用。
本次實作不會自動部署或推送；先完成本機驗收。
