# 台灣麻將台數計算表

mahjong16 預設使用 `common` 場規與 `taiwan_base` 計分表，底為 100 點，每台 20 點。
下表列的是各台種的基準台數。實際胡牌條件、台種能否疊加，以及四家的收付，
由[場規](../domain/rules/)和[計分引擎](../domain/scoring/)判定。

例如，門清自摸在一般自摸時合計 3 台，門清與自摸不再另外加台。
莊家加台隨連莊次數變動，未連莊時為 1 台，每連莊一次多 2 台。
[計分回歸測試](../tests/scoring/)涵蓋台種組合與自摸、放槍的收付。

## 計分設定

用 Python 呼叫引擎時，可以透過 `Ruleset.scoring_profile` 指定計分表，
或用 `Ruleset.scoring_overrides_path` 指向自己的 JSON。切換計分表會調整基準台數，
胡牌條件仍依 mahjong16 的場規判定。

| 計分設定 | 設定檔 | 原整理所列來源 |
| --- | --- | --- |
| 預設 | [`taiwan_base`](../configs/scoring/profiles/taiwan_base.json) | 原整理的主表 |
| 明星三缺一 | [`gametower_star31`](../configs/scoring/profiles/gametower_star31.json) | [原場規頁](https://www.gametower.com.tw/Games/Freeplay/MJ/Star31/Data/count.aspx) |
| MJ888 | [`mj888`](../configs/scoring/profiles/mj888.json) | 原整理未記錄網址 |
| 中華競技麻將網 | [`zhonghua`](../configs/scoring/profiles/zhonghua.json) | 原整理記為 `atawmj.org.tw`，本次核對未能連線 |
| 宅神爺 | [`zhaishenye`](../configs/scoring/profiles/zhaishenye.json) | [原場規頁](https://www.bonuswinner.com.tw/winner/game/mj/01_count.html) |
| 麻將大師 | [`mahjong_masters`](../configs/scoring/profiles/mahjong_masters.json) | [原場規頁](https://mahjongmasters.com/rules/) |

原整理沒有保存逐項擷取日期或來源版本。調整計分設定前，請核對原始場規並補上回歸測試。
台種的程式用名稱可查[計分標籤](../configs/scoring/labels.json)。
